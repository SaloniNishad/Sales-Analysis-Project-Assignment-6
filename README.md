# Sales Data Analysis Project

## 1\. Project Overview

This project analyzes sales data using Microsoft Excel and Power BI to understand sales performance, profit, product categories, regions, and customer segments.

## 2\. Problem Statement

The objective is to identify sales trends, understand profitable categories and regions, and provide useful recommendations to improve business performance.

## 3\. Dataset

The project uses a Superstore sales dataset containing order details, order dates, product categories, customer segments, regions, sales, quantity, discounts, and profit.

## 4\. Tools Used

* Microsoft Excel — data cleaning and preparation.
* Microsoft Power BI — data analysis, DAX measures, charts, and dashboard.
* Git and GitHub — version control and project documentation.

## 5\. Data Cleaning

* Checked and corrected data types.
* Removed duplicate Row IDs.
* Removed blank rows in Order Date.
* Checked invalid values in numeric columns.
* Filled missing Postal Code values using the mode.
* Created a Profit Status column.

## 6\. Exploratory Data Analysis (EDA)

Created DAX measures to calculate Total Sales, Total Profit, Total Quantity, and Total Orders. Examined sales trends and compared categories, regions, customer segments, and sales against profit.

## 7\. Visualizations and Dashboard

The Power BI dashboard contains four KPI cards and five charts:

* Yearly Sales Trend
* Category-wise Sales
* Region-wise Profit
* Total Sales by Segment
* Sales vs Profit

Slicers allow users to filter the dashboard by Year, Month, Category, and Segment.

## 8\. Key Insights

* Technology generated the highest category sales.
* The West region had the highest share of total profit.
* The Consumer segment generated the highest sales.
* Sales increased between 2015 and 2018 in the displayed trend.
* Some transactions had negative profit, requiring further investigation.

## 9\. Recommendations

* Promote profitable products and study successful strategies in the West region.
* Review discounts, costs, and pricing for loss-making transactions.
* Develop suitable marketing campaigns for Consumer customers.

## 10\. Conclusion

This project demonstrates how data cleaning, exploratory analysis, visualization, and Power BI dashboards can help businesses understand performance and make data-driven decisions.
